# cli-anything-mermaid

Agent-native CLI for Mermaid diagrams: author, render (mmdc/HTTP), and verify diagrams.

> Generated by `cli-anything-new`. The harness boilerplate (clap surface,
> reedline REPL, `--json` envelope, auto-save, SKILL.md emitter) is in place;
> fill in the domain logic in `src/domain/` and the real backend calls in
> `src/backend.rs`.

## Prerequisites

- The real **Mermaid** backend on `PATH` (see `src/backend.rs`).

## Build & install

```bash
cargo build -p cli-anything-mermaid
cargo install --path crates/cli-anything-mermaid   # puts `cli-anything-mermaid` on PATH
```

## Usage

```bash
cli-anything-mermaid project new --title "demo"      # one-shot
cli-anything-mermaid --json session status           # machine-readable
cli-anything-mermaid                                  # no subcommand → REPL
```

- Every command supports `--json`. Output is a uniform envelope:
  `{ok, action, data, error, warnings}` (`ok=false` + `error.kind/message/hint`
  on failure).
- Global flags: `--project <path>`, `--dry-run`.
- One-shot mutations auto-save to the open project unless `--dry-run`.

## Regenerate SKILL.md

```bash
cli-anything-mermaid emit-skill -o crates/cli-anything-mermaid/SKILL.md
```

The SKILL is derived from the live clap command tree, so it never drifts.

## Tests

```bash
cargo test -p cli-anything-mermaid                 # unit tests
cargo test -p cli-anything-mermaid -- --ignored    # e2e (needs the real backend)
```
