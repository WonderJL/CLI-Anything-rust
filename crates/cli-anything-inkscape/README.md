# cli-anything-inkscape

Agent-native CLI for Inkscape: build SVG documents, export via real inkscape, safely import untrusted SVG.

> Generated by `cli-anything-new`. The harness boilerplate (clap surface,
> reedline REPL, `--json` envelope, auto-save, SKILL.md emitter) is in place;
> fill in the domain logic in `src/domain/` and the real backend calls in
> `src/backend.rs`.

## Prerequisites

- The real **Inkscape** backend on `PATH` (see `src/backend.rs`).

## Build & install

```bash
cargo build -p cli-anything-inkscape
cargo install --path crates/cli-anything-inkscape   # puts `cli-anything-inkscape` on PATH
```

## Usage

```bash
cli-anything-inkscape project new --title "demo"      # one-shot
cli-anything-inkscape --json session status           # machine-readable
cli-anything-inkscape                                  # no subcommand → REPL
```

- Every command supports `--json`. Output is a uniform envelope:
  `{ok, action, data, error, warnings}` (`ok=false` + `error.kind/message/hint`
  on failure).
- Global flags: `--project <path>`, `--dry-run`.
- One-shot mutations auto-save to the open project unless `--dry-run`.

## Regenerate SKILL.md

```bash
cli-anything-inkscape emit-skill -o crates/cli-anything-inkscape/SKILL.md
```

The SKILL is derived from the live clap command tree, so it never drifts.

## Tests

```bash
cargo test -p cli-anything-inkscape                 # unit tests
cargo test -p cli-anything-inkscape -- --ignored    # e2e (needs the real backend)
```
